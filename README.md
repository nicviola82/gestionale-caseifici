# Gestionale Caseifici - Fase 1

Contenuto di questa Fase 1:
- Login (email + password) con due ruoli: owner e caseificio
- Selezione del caseificio con cui lavorare
- Anagrafica caseificio + refrigeranti
- Conferitori di latte (con dati sanitari, documenti, avvisi scadenze)
- Prodotti

## File
- `schema_fase1.sql` -> da incollare nel SQL Editor di Supabase
- `app.py` -> pagina principale (login + scelta caseificio)
- `pages/` -> le altre pagine del menu
- `db.py`, `auth.py` -> blocchi di supporto
- `requirements.txt` -> librerie necessarie, le legge Streamlit da solo
